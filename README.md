# 需求预测与库存优化系统

## 项目简介

本项目是一个基于历史销售数据的需求预测系统，旨在帮助商家和仓库管理者准确预测未来需求量，优化库存管理，特别是针对新品上市和促销期间的特殊需求模式。

## 功能特点

- **常规需求预测**：基于历史数据的时间序列分析
- **新品冷启动预测**：针对新商品/新仓库的预测方法
- **促销期间预测**：基于历史促销数据的618/双十一等大促预测
- **序列分类**：根据需求特征自动分类，采用不同预测策略

## 预测方法

### 1. 常规需求预测
- **预测范围**：2023-05-16 至 2023-05-30（15天）
- **方法**：基于序列分类的智能预测
  - 稳定季节型：季节性分解 + 趋势调整
  - 一般波动型：趋势外推法
  - 间歇型：Croston模型
  - 大宗商品型：趋势预测
  - 极端波动型：概率中位数法

### 2. 新品需求预测
- **预测范围**：2023-05-16 至 2023-05-30（15天）
- **方法**：分层参考策略
  - 优先使用自身数据（≥14天）
  - 商家+仓库聚合参考
  - 商品类别参考
  - 全局均值兜底

### 3. 促销期间预测
- **预测范围**：2023-06-01 至 2023-06-20（20天）
- **方法**：基于双十一模式的618预测
  - 促销放大系数计算
  - 日级需求模式分析
  - 周末效应调整
